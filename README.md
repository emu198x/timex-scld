# timex-scld

The Timex SCLD of the TC2048, TC2068 and TS2068.

| Crate | Registry |
|---|---|
| [`emu198x-timex-scld`](crates/emu198x-timex-scld) | [crates.io](https://crates.io/crates/emu198x-timex-scld) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the TC2048 and TS2068.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
